# `assets/narrators/` của project này

Bỏ ảnh nhân vật kể chuyện dành riêng cho **project demo_story_inside** vào đây.

- Thư mục này được đọc **trước** `<repo>/assets/narrators/`, nên ảnh cùng tên ở đây sẽ thắng.
- Bấm **Lam moi thu vien** trong Studio để danh sách cập nhật.
- Chọn ảnh sẽ ghi `story_frame.image_file = "assets/narrators/<ten_file>.png"` vào
  `script.json` của project này.

Xem `assets/narrators/README.md` ở gốc repo để biết đầy đủ quy tắc (kích thước, nền trong suốt,
khi nào cần registry để nhân vật "nói chuyện").
